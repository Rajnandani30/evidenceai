# EvidenceAI

EvidenceAI is a hybrid-search Retrieval-Augmented Generation (RAG) application designed to provide evidence-grounded answers from uploaded documents.

The project combines:

* Dense vector search
* BM25 keyword search
* Hybrid retrieval
* Cross-encoder reranking
* Source-based answer generation
* Citation-support verification

## Project Status

🚧 Currently under development.
